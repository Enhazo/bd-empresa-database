# Banco de Dados — Empresa

Script SQL didático para criar o banco `EMPRESA` e as tabelas de cidades, funções, locais, departamentos e funcionários, com chaves e relacionamentos.

## Conteúdo

- `database.sql` — criação do banco e das tabelas (T-SQL para Microsoft SQL Server).
- `docs/modelo-relacional.png` — diagrama visual do modelo relacional.

## Como executar

Abra `database.sql` no SQL Server Management Studio, Azure Data Studio ou execute com `sqlcmd -i database.sql`. O script cria o banco `EMPRESA`; use uma instância de desenvolvimento/teste.

O diagrama é uma imagem para consulta. Os arquivos editáveis originais do brModelo não foram incluídos.
