# Banco de Dados — Empresa

Script SQL de exercício para criação do banco `EMPRESA` e das tabelas de cidade, função, local, departamento e funcionário, com chaves e relacionamentos.

## Como usar

Abra `database.sql` em um ambiente compatível com Microsoft SQL Server e execute o script. Ele cria o banco de dados `EMPRESA`.
